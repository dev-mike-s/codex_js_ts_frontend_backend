Section

Section (dt. Abschnitt) => beschreibt einen thematisch zusammengehörigen Inhaltsbereich einer Webseite.

Sollte fast immer eine Überschrift enthalten, die diesen Abschnitt erklärt.

section class="wrapper"

Ohne Überschrift, mit div und div Inhalt

Wrapper

Wrapper => Wrapper ist kein (semantisches) html-Element. Wird oft genutzt mit div um Inhalte für layout, styling, js zu kapseln.

Best practice ist div class wrapper dann section (mit weiteren html elementen für ordentliche Semantik).

Div

Semantikloser Block-Container zur Gruppierung von Elementen. Wird verwendet für layout, styling und js-Logik - wenn - kein semantisches Element passt.
